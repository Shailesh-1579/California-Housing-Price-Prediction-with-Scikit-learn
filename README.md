# End-to-End California Housing Price Prediction

This project is a complete demonstration of a machine learning workflow for predicting median house values in California districts, based on the 1990 census data.

It uses the classic California Housing dataset and builds a robust Scikit-learn pipeline for data preprocessing. The project showcases two distinct Python scripts: one for model analysis and another for a complete train-and-infer operational pipeline.

## Core Features

* **Robust Preprocessing**: Uses Scikit-learn's `ColumnTransformer` and `Pipeline` to handle numerical and categorical data cleanly.
    * **Numerical Pipeline**: Imputes missing values (e.g., `total_bedrooms`) using the median and applies `StandardScaler`.
    * **Categorical Pipeline**: Applies `OneHotEncoder` to the `ocean_proximity` feature.
* **Stratified Splitting**: Ensures the training and test sets are representative of the dataset's `median_income` distribution.
* **Model Comparison**: `main.py` evaluates and compares three different regression models (Linear Regression, Decision Tree, Random Forest) using 10-fold cross-validation to find the most robust.
* **Train/Inference Workflow**: `main_new.py` provides a full, operational workflow:
    * **Training Phase**: Trains the best model (RandomForest) and saves the `model.pkl` and `pipeline.pkl` files.
    * **Inference Phase**: If a model already exists, it loads the saved files, runs predictions on a test set (`input.csv`), and saves the results to `output.csv`.

## File Structure

* **`main.py`**: (Script 1 - Analysis) Loads `housing.csv`, builds a pipeline, and runs 10-fold cross-validation to compare Linear Regression, Decision Tree, and Random Forest models. Prints RMSE statistics for each.
* **`main_new.py`**: (Script 2 - Operational) The primary workflow script.
    * If `model.pkl` doesn't exist, it runs the **Training Phase**.
    * If `model.pkl` *does* exist, it runs the **Inference Phase**.
* **`housing.csv`**: The complete, raw dataset used for training.
* **`input.csv`**: The test data (20% of the original data), automatically created by `main_new.py` during its first (training) run.
* **`output.csv`**: The final predictions. This file is generated by `main_new.py` during its inference phase. It contains the data from `input.csv` with a new `median_house_value` prediction column.
* **`pipeline.pkl`**: The saved, fitted `ColumnTransformer` pipeline. Generated by `main_new.py` during training.
* **`model.pkl`**: (Not provided, but generated by `main_new.py`) The saved, trained `RandomForestRegressor` model.

## How to Use This Project

This project has two main workflows.

### Workflow 1: Analyze Model Performance

If you want to see how different models compare, run `main.py`.

1.  Make sure you have `housing.csv` in the same directory.
2.  Run the script:
    ```bash
    python main.py
    ```
3.  **Output**: The console will print descriptive statistics (mean, std, min, max, etc.) for the 10-fold cross-validation RMSE scores for Linear Regression, Decision Tree, and Random Forest. This helps justify *why* Random Forest was chosen for the operational script.

### Workflow 2: Run the Full Train-and-Infer Pipeline

This workflow uses `main_new.py` and shows how the project would work in a production-like environment.

1.  **Step 1: Train the Model**
    * Make sure `housing.csv` is present.
    * Delete any existing `model.pkl`, `pipeline.pkl`, `input.csv`, or `output.csv` files to ensure a fresh training run.
    * Run the script:
        ```bash
        python main_new.py
        ```
    * **Output**: The script will print `"Model trained and saved."`. It has now:
        * Trained a Random Forest model on 80% of the data.
        * Saved the test set (the other 20%) as `input.csv`.
        * Saved the fitted pipeline as `pipeline.pkl`.
        * Saved the trained model as `model.pkl`.

2.  **Step 2: Run Inference**
    * Now that the model files exist, run the *exact same script again*:
        ```bash
        python main_new.py
        ```
    * **Output**: The script will print `"Inference complete. Results saved to output.csv"`. It has:
        * Loaded `model.pkl` and `pipeline.pkl`.
        * Loaded `input.csv`.
        * Transformed the input data and made predictions.
        * Saved the predictions to `output.csv`.
